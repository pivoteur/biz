# code reviews

What are reasons to have a code review?

* does the code have security vulnerabilities?
* does the code work?
* are there redundancies?
* what is the test coverage?
* does it meet the requirement?

and:

* does corporate require me to do a code review?

Which prompts work best?

## Rock Lobstah

If your prompt to AI is: "do a code review," it'll do a code review. Does it 
do the code review you want?

"You should use f64 instead of f32 on line 121."

Really? WRONG!

But you are the manager who told AI to get you a rock. And it got you a rock. 
Congratulations, dumbass.

But these prompts:

* "Point out security vulnerabilities and provide guards"
* "Ensure test coverage is at least 80% of code. Write unit tests."
* "Extract and refactor all redundancies."

They're not 'do a code review.' No, they are specific questions addressing 
specific concerns.

I don't think people are smart enough to use AI.

Why? Because AI does what they tell it to do, but people complain that AI did 
the job they asked.

I think everybody who uses AI should have a mirror.

Why? That way they can ask the mirror: "Who's the dumbass here?" when AI does exactly what they told it to do.

On the other hand, you can totally be a dumbass and use AI to bootstrap yourself into competency.

How?

## Competency

* "Okay, that's not what I meant [trans: 'I'm a dumbass']. Can we introduce 
resources via dependency injection instead?"

* "Okay, that code didn't work with this error [paste]. How do I fix it?"

* "Can we introduce structures to encompass this domain instead of using 
if-else?"

## Learning

Then when the code finally compiles, when it finally runs, and when it finally 
does what you intended it to do, THEN you go back to the code-review 
questions (remember those?), the REAL code review questions, to make your code 
secure, succinct, clear, and intentional.

## Conclusion

AI is a tool.

Senior Chief Kokel, USCG (retired), said time and again: "2% rule, sir."

You have to be 2% smarter than the tool you're using. Most people want AI to 
give 'The Answer.'™️

Be 2% smarter.

Use AI to teach you to ask better questions, THEN you'll get better answers.
