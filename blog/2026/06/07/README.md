# `dusk` tweak

Hwæt, pivoteurs!

A tweak to `dusk` that makes close-pivot calls: it now recommends close pivots 
in order of greatest volume, first.

![`dusk` calls, sorted by volume](imgs/01-dusk.png)

This allows me to attack close pivots with the greatest impact. As time is 
finite for me, this is a great help moving toward full-automation.
